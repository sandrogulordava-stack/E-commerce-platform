# ტექნო მაღაზია — გაშვება და ნაწილების შეერთება

საჭიროა Node.js 22.12+ და npm. ეს პროექტი ძველი ონლაინ მაღაზიის უცვლელი წყაროა, განახლებული შეფუთვითა და ახსნით.

## გაშვება

VS Code-ში გახსენით ის საქაღალდე, სადაც package.json მდებარეობს: full-project, 01_individual_work ან 02_integrated_project.

```bash
npm ci
npm run dev
```

გახსენით ტერმინალში მითითებული ადგილობრივი მისამართი. ტესტები და აწყობა:

```bash
npm test
npm run build
npm run preview
```

React 18.3.1 შენარჩუნებულია PropTypes-ის ავტომატური შემოწმებისთვის. package.json, lock, Vite კონფიგურაცია და საერთო წყარო ყველა ვერსიაში ერთია.

## ინდივიდუალური და გაერთიანებული ნაწილი

თითოეულ სტუდენტურ ZIP-ში 01_individual_work შეიცავს შესაბამისი სტუდენტის მოდულსა და დამოუკიდებლად გასაშვებად აუცილებელ საერთო ინფრასტრუქტურას. სხვა სტუდენტების კომპონენტები მასში არ არის. საერთო Provider-ს ესაჭიროება სტუდენტი 2-ის useLocalStorage, ამიტომ მისი უცვლელი ასლიც აუცილებელი საერთო დამოკიდებულებაა.

02_integrated_project შეიცავს ოთხივე მოდულს, build-ით შექმნილ dist-ს და info.md-ს. ოთხივე სტუდენტის ეს საქაღალდე ერთნაირია. ასევე ცალკე მოგეწოდებათ full-project.zip იგივე სრული პროექტით.

MD განმარტებაში აღწერილია თითოეული კომპონენტი, Hook, ფუნქცია, props, საერთო კონტექსტი და მოვლენები; ბოლოში დართულია სტუდენტის საკუთარი კოდი.

## ხელით შეერთება

აიღეთ სტუდენტი 1-ის 01_individual_work საწყის ბაზად. სტუდენტი 2-დან დაამატეთ src/components/student2, src/utils/cart.js და tests/student2.test.jsx. useLocalStorage უკვე საერთო ბაზაშია. სტუდენტი 3-დან დაამატეთ src/components/student3, src/hooks/student3, src/utils/reviews.js და tests/student3.test.jsx. სტუდენტი 4-დან დაამატეთ src/components/student4, src/hooks/student4 და tests/student4.test.jsx. საერთო ფაილები ბაიტობრივად იდენტურია და არ შეცვალოთ. App ავტომატურად იპოვის ოთხივე მოდულს. ოთხივე მოდულის საერთო ინტეგრაციის ტესტი სრული პროექტის tests/integration.test.jsx-შია.
