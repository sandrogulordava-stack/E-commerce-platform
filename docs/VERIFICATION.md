## რას ამოწმებს ტესტები

- სიმულაციური ჩატვირთვა, საძიებო ფოკუსი, დაყოვნებული ძებნა, კატეგორია და გასუფთავება.
- კატალოგის callback-ით კალათასა და რჩეულებში დამატება.
- კალათის აღდგენა, რაოდენობის ცვლილება, მარაგის ზღვარი და წაშლა.
- არასწორი კუპონი, სწორი კუპონი, 10% ფასდაკლება და გაუქმება.
- სატესტო შეკვეთა და კალათის გასუფთავება.
- მიმოხილვის სამი ვალიდაციის შეცდომა, ვარსკვლავების არჩევა და ახალი შეფასება.
- საშუალო რეიტინგის განახლება, პროდუქტის შეცვლა, შენახვა და scrollIntoView-ის გამოძახება.
- რჩეულების ძებნა, დალაგება, კალათაში გადატანა და წაშლა.
- რჩეულის შენარჩუნება, თუ კალათაში მარაგის მაქსიმუმია.
- დაზიანებული შენახული მონაცემები, შენახვის აკრძალვა და PropTypes-ის არასწორი props-ის შეტყობინება.
- გლობალური ვალუტის შეცვლა და სრული გადამონტაჟების შემდეგ კალათის აღდგენა.

DOM ტესტები შესრულდა jsdom-ში. რეალურ ბრაუზერში ვიზუალური დათვალიერება არ ჩატარებულა; ეს ანგარიში არ ამტკიცებს ბრაუზერულ ვიზუალურ შემოწმებას. CSS-ში გათვალისწინებულია კომპიუტერისა და ტელეფონის სიგანეები, focus სტილები და გადატანადი განლაგება.

## წყაროს იდენტურობა

შეფუთვის ცვლილებამდე და შემდეგ სრული პროექტის src ფაილები ბაიტობრივად იდენტურია. თითოეული ინდივიდუალური src ფაილი შესაბამისი სრული src ფაილის იგივე ასლია. თითოეულის source-manifest.json ინახავს SHA-256 მნიშვნელობებს. ოთხივე სტუდენტის 02_integrated_project იდენტურია ცალკე მოწოდებული full-project-ისა, მათ შორის dist.

სრული პროექტის 10 ტესტი და ოთხივე დამოუკიდებელი პაკეტის ტესტები/აწყობა ახალ შეფუთვაშიც შემოწმდა. ორიგინალის სარედაქციო ახსნები განახლდა. კოდის ფუნქციონალი არ შეცვლილა.

## კრიტერიუმების მიმოხილვა

ოთხივე მთავარ მოდულში პირდაპირ იმპორტირებული და გამოყენებულია ექვსივე ნებადართული React Hook. თითოეულს აქვს თავისი Custom Hook. სხვა React Hook არ გამოიყენება. მონაცემების და callback props-ის მქონე კომპონენტებს აქვთ PropTypes; საერთო და ინდივიდუალური wrapper-ები იყენებს children-ს.

სწავლის შედეგი 1-ის ინსტალაცია, პირადი GitHub ისტორია და ინდივიდუალური ახსნა თითოეულმა სტუდენტმა თავად უნდა დაადასტუროს. GitHub-ზე ატვირთვა და LMS-ში ჩაბარება არ შესრულებულა. LMS შეფუთვა მოწოდებული სქემითაა მომზადებული; პირადი სახელები, ჯგუფის ნომერი და GitHub-ის ბმულები შესავსებია. ოთხკაციანი ფორმატის დამტკიცება ამ კოდის შემოწმების ფარგლებს სცდება.
